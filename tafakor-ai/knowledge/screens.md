# Screen map (routes of the React app)

| Route | Screen | Main actions |
|---|---|---|
| `/` | Dashboard | — |
| `/accounts` | Chart of accounts | new account |
| `/parties`, `/parties/:id` | Parties (customers/suppliers/others) | new party |
| `/journal`, `/journal/new`, `/journal/:id` | Journal entries | new, post, cancel |
| `/sales/invoices`, `/sales/quotations`, `/sales/returns` (+ `/new`, `/:id`) | Sales | new invoice |
| `/purchases/invoices`, `/purchases/returns` | Purchases | new invoice |
| `/treasury` | Cash & bank accounts | new account |
| `/treasury/transactions` | Receipts, payments, transfers | **New receipt**, New payment, New transfer (dialog) |
| `/expenses` | Expenses | **New expense** (dialog) |
| `/cost-centers` | Cost centers / departments / projects | new |
| `/checks`, `/checks/new`, `/checks/:id` | Checks | — |
| `/payroll/...` | Payroll | — |
| `/budgets/...` | Budgets and budget control | — |
| `/reports`, `/reports/:report` | Reports: journal, ledger, trial-balance, profit-loss, balance-sheet, cash-position, receivables, payables, sales, purchases, expenses, cost-centers | export PDF/Excel |
| `/settings/company`, `/settings/fiscal-years`, `/settings/posting-rules`, `/settings/users`, `/settings/roles`, `/settings/audit` | Settings | — |

The machine-readable version (fields and action tags) is `ai-map.json`, generated by `widget/scripts/gen-map.mjs`.
